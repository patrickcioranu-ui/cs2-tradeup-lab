MODEL NOTES

Transparent by design.

Collection selection is weighted by the number of inputs from each collection. Outputs inside a selected collection are treated as equally likely. Prices are representative quotes, not guarantees; spreads, volatility, trade locks and platform fees can change the result.

Expected value EV = Σ P(output) × net sale price − input cost
